\section{Security \& Configuration Enforcements}
\begin{itemize}[leftmargin=*, itemsep=0.8em]
    \item \textbf{CORS Restricted}: The \code{app/main.py} CORS configuration now restricts origins to typical local frontend ports (\code{3000} and \code{5173}), resolving the browser blocking issue caused by the wildcard \code{*} combined with \code{allow\_credentials=True}.
    \item \textbf{JWT Lifespan}: Access tokens now expire after \textbf{60 minutes} instead of a full 24 hours, limiting the window of exposure.
    \item \textbf{SECRET\_KEY Enforced}: Removed the unsafe default string for \code{SECRET\_KEY} in \code{app/core/config.py}. It must now be loaded securely from the \code{.env} file.
    \item \textbf{Graceful JWT Error Handling}: \code{app/dependencies.py} now gracefully catches \code{json.JSONDecodeError} alongside \code{JWTError}, preventing raw HTTP 500 crashes if a token's embedded JSON payload is malformed.
\end{itemize}

\section{Multi-Tenant Isolation}
\begin{itemize}[leftmargin=*, itemsep=0.8em]
    \item \textbf{Cross-Plant Protection}: A new helper function \code{\_get\_invoice\_for\_user()} was added to the \code{invoice\_workflow.py} service. It enforces that a Store or Accounts Officer from Plant 1 cannot fetch, view, or modify an invoice belonging to Plant 2. All endpoints now strictly leverage this helper.
\end{itemize}

\section{Workflow Logic \& State Machine Fixes}
\begin{itemize}[leftmargin=*, itemsep=0.8em]
    \item \textbf{NoneType Guard}: The \code{confirm\_inspection} endpoint now explicitly verifies that a \code{MaterialReceipt} actually exists before attempting to access its \code{acceptance\_type} property.
    \item \textbf{Dynamic Observation Rounds}: When \code{verify\_invoice} determines that observations were found, it no longer hardcodes \code{round\_number=1}. Instead, it dynamically queries the database for the max round number for that invoice and increments it. This allows for endless back-and-forth iteration loops with external firms without triggering SQLAlchemy \code{IntegrityError}s.
    \item \textbf{Timezone Standardization}: In \code{close\_current\_stage}, dates are now stripped of their \code{tzinfo} immediately prior to subtraction, standardizing the timezone delta calculation. This prevents Python \code{TypeError} crashes caused by SQLite's timezone handling.
    \item \textbf{Audit Event Integrity}: Removed the redundant assignment of \code{current\_stage\_entered\_at} in \code{create\_invoice}, routing all timestamp generation exclusively through \code{open\_new\_stage()} to prevent millisecond drift in the audit trail.
    \item \textbf{Relationships Fixed}: Added \code{stage\_events} bidirectional relationships to both the \code{Invoice} and \code{StageEvent} SQLAlchemy models so that API responses can seamlessly return the entire audit trail history via lazy loading.
\end{itemize}

\section{Endpoints Exposed}

    \item \code{POST /invoices/\{invoice\_id\}/verify}
\end{itemize}
